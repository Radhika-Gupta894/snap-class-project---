# SnapClass AI 📸🎙️

SnapClass is a next-generation classroom management and AI-powered attendance system. It leverages advanced **Computer Vision** (face recognition) and **Voice Biometrics** (voice matching) to track student attendance instantly, securely, and seamlessly.

---

## 🚀 Key Features

*   **AI Face Recognition**: Identify and log attendance for all students from a single class photo.
*   **Voice ID Attendance**: Sequential voice validation matching voice patterns against stored embeddings.
*   **Dynamic Roster**: QR-code and join-link course registration.
*   **Dual-Server Portal**:
    *   Flask-driven landing page for branding and navigation.
    *   Streamlit-driven dashboard for teachers and students.

## 💻 Local Setup & Running

### 1. Clone the repository and configure Virtual Environment
```bash
git clone <your-repository-url>
cd snap_class_project

# Create a virtual environment
python -m venv venv
source venv/Scripts/activate  # On Windows: venv\Scripts\activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Setup Secrets File
Create a `.streamlit/secrets.toml` file in the root directory:
```toml
supabase_URL = "https://your-project-id.supabase.co"
supabase_API = "your-anon-public-key"
```

### 4. Run the Servers

*   **To run the Landing Page** (Flask):
    ```bash
    python frontend/app.py
    ```
    View landing page at: `http://localhost:5002`

*   **To run the Dashboard App** (Streamlit):
    ```bash
    streamlit run app.py
    ```
    View app at: `http://localhost:8501`

## 🗄️ Database Setup (Supabase)

Go to your **Supabase Dashboard** -> **SQL Editor** -> **New Query**, paste the following script, and click **Run**:

```sql
-- Create teachers table
CREATE TABLE teachers (
    username TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    password TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Create students table
CREATE TABLE students (
    student_id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    face_embeddings JSONB,
    voice_embeddings JSONB,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Create subjects table
CREATE TABLE subjects (
    code TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    section TEXT NOT NULL,
    teacher_username TEXT REFERENCES teachers(username) ON DELETE CASCADE,
    join_code TEXT UNIQUE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Create subject_students table
CREATE TABLE subject_students (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    student_id TEXT REFERENCES students(student_id) ON DELETE CASCADE,
    subject_id TEXT REFERENCES subjects(code) ON DELETE CASCADE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    UNIQUE(student_id, subject_id)
);

-- Create attendance table
CREATE TABLE attendance (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    subject_id TEXT REFERENCES subjects(code) ON DELETE CASCADE,
    student_id TEXT REFERENCES students(student_id) ON DELETE CASCADE,
    is_present BOOLEAN NOT NULL DEFAULT false,
    date DATE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Disable Row-Level Security for direct app access
ALTER TABLE teachers DISABLE ROW LEVEL SECURITY;
ALTER TABLE students DISABLE ROW LEVEL SECURITY;
ALTER TABLE subjects DISABLE ROW LEVEL SECURITY;
ALTER TABLE subject_students DISABLE ROW LEVEL SECURITY;
ALTER TABLE attendance DISABLE ROW LEVEL SECURITY;
ALTER TABLE IF EXISTS attendance_logs DISABLE ROW LEVEL SECURITY;
```

## ☁️ Deployment

### Deployed Streamlit Cloud Settings
When deploying the app to **Streamlit Community Cloud**, paste your Supabase secrets in **Settings > Secrets**:
```toml
supabase_URL = "https://your-active-project.supabase.co"
supabase_API = "your-anon-key"
```

### Deployed Landing Page Settings
Set the environment variable on your Flask host (e.g. Render / Vercel):
`STREAMLIT_URL=https://your-app-name.streamlit.app`
